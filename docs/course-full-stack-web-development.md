# Full-Stack Web Development

## At a glance

- Duration: 24 weeks
- Fee: Rs 85,000
- Live classes: Monday, Wednesday and Friday, 8-10 pm IST
- Prerequisites: none

## Who it is for

This course is for people who want to become web developers and are starting from scratch or close to it. It suits:

- College students and recent graduates with no professional coding experience
- Working professionals moving into software from another field
- Self-taught learners who know some HTML or JavaScript and want a structured path to a complete, deployable project

The evening schedule is designed to fit around a full-time job or college.

## What you will be able to do

By the end you will have built and deployed a full web application with a React front end, a Node.js API and a database, and you will be able to explain the design decisions behind it in an interview.

## Course outline

- Weeks 1-2: How the Web Works, HTML and CSS
- Weeks 3-5: JavaScript Fundamentals
- Weeks 6-7: Git, the Command Line and Developer Tooling
- Weeks 8-11: React and Front-End Application Design
- Weeks 12-14: Node.js and Express APIs
- Weeks 15-17: Databases with SQL and MongoDB
- Weeks 18-19: Authentication, Security and Testing
- Weeks 20-21: Deployment and Continuous Integration
- Weeks 22-24: Capstone Project and Interview Preparation

## How the course runs

Each live class is two hours and mixes teaching with hands-on coding. Recordings are available within 24 hours if you miss a class, but attendance counts towards placement eligibility, so attend live when you can.

Assignments are set every week and are graded. You also get two 1:1 mentor sessions per month to review your code and progress.

## Payment options

At Rs 85,000 this course qualifies for no-cost EMI over 3, 6 or 9 months. You can also take the entrance test for a scholarship of up to 30% of the fee.

## Pausing the course

You can pause once for up to 8 weeks, as long as you request it before week 12. See the course pause policy.
