# Data Science and Machine Learning

## At a glance

- Duration: 28 weeks
- Fee: Rs 95,000
- Live classes: Tuesday, Thursday and Saturday, 8-10 pm IST
- Prerequisite: basic Python

## Who it is for

This course is for people who want to work as data analysts, data scientists or machine learning engineers. It suits:

- Engineers and analysts who already write some Python and want to move into data roles
- Graduates from maths, statistics, science or engineering backgrounds
- Working professionals who handle data in spreadsheets and want to move to code and models

## What "basic Python" means

You should be comfortable with variables, loops, functions, lists and dictionaries, and be able to write a short script without help. You do not need to know NumPy, pandas or any machine learning library. If you are unsure, write to support and we will share a short self-check exercise.

## Course outline

- Weeks 1-3: Python for Data Analysis with NumPy and pandas
- Weeks 4-5: SQL and Data Wrangling
- Weeks 6-8: Statistics and Probability
- Weeks 9-10: Data Visualisation and Exploratory Analysis
- Weeks 11-14: Supervised Learning
- Weeks 15-16: Unsupervised Learning
- Weeks 17-18: Feature Engineering and Model Evaluation
- Weeks 19-22: Deep Learning Foundations
- Weeks 23-24: Natural Language Processing
- Weeks 25-26: Model Deployment and MLOps Basics
- Weeks 27-28: Capstone Project and Interview Preparation

## How the course runs

Each live class is two hours. Most classes include a worked notebook that you finish as part of the weekly assignment. Recordings are available within 24 hours of each class.

You get two 1:1 mentor sessions per month. Learners usually use these for assignment feedback, capstone planning and interview practice.

## Payment options

At Rs 95,000 this course qualifies for no-cost EMI over 3, 6 or 9 months. Scholarships of up to 30% of the fee are available based on your entrance test score.

## Pausing the course

You can pause once for up to 8 weeks, as long as you request it before week 12. See the course pause policy.
