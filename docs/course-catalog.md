# Course Catalog

Skilvanta runs four courses. Three are taught through live online classes and one is self-paced with a weekly live doubt session. All times are in IST.

## Summary

| Course | Duration | Fee | Schedule | Prerequisites |
| --- | --- | --- | --- | --- |
| Full-Stack Web Development | 24 weeks | Rs 85,000 | Live classes Mon/Wed/Fri, 8-10 pm IST | None |
| Data Science and Machine Learning | 28 weeks | Rs 95,000 | Live classes Tue/Thu/Sat, 8-10 pm IST | Basic Python |
| Backend Engineering with Python | 16 weeks | Rs 60,000 | Live classes Sat/Sun, 10 am-1 pm IST | One programming language |
| DSA and Interview Prep | 10 weeks | Rs 30,000 | Self-paced, with one live doubt session every Sunday at 6 pm IST | None |

## Full-Stack Web Development

A 24-week course that takes a beginner from HTML and JavaScript to deploying a complete web application. Fee: Rs 85,000. Live classes run Monday, Wednesday and Friday from 8 to 10 pm IST. There are no prerequisites.

## Data Science and Machine Learning

A 28-week course covering data analysis, statistics, machine learning and an introduction to deep learning. Fee: Rs 95,000. Live classes run Tuesday, Thursday and Saturday from 8 to 10 pm IST. You need basic Python before you start.

## Backend Engineering with Python

A 16-week weekend course on building, testing and deploying backend services in Python. Fee: Rs 60,000. Live classes run Saturday and Sunday from 10 am to 1 pm IST. You need working knowledge of one programming language.

## DSA and Interview Prep

A 10-week self-paced course on data structures, algorithms and coding interviews. Fee: Rs 30,000. There is one live doubt session every Sunday at 6 pm IST. There are no prerequisites.

## What every course includes

- Class recordings, available within 24 hours of each live class
- Two 1:1 mentor sessions per month
- Graded assignments
- A certificate for learners who meet the score requirement
- Placement support for learners who meet the eligibility criteria

## Paying for a course

No-cost EMI is available on courses costing Rs 50,000 or more, and scholarships of up to 30% of the fee are awarded based on an entrance test score. See the page on payments, EMI and scholarships for details.
