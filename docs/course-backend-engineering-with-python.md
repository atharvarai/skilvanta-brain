# Backend Engineering with Python

## At a glance

- Duration: 16 weeks
- Fee: Rs 60,000
- Live classes: Saturday and Sunday, 10 am-1 pm IST
- Prerequisite: one programming language

## Who it is for

This course is for people who can already program and want to build production-style backend services. It suits:

- Front-end or mobile developers who want to work on the server side
- Developers from Java, JavaScript, C++ or another language who want to switch to Python
- Working professionals who can only study on weekends

## About the prerequisite

You need working knowledge of one programming language, in any language. You should understand functions, loops, basic data structures and how to run and debug a program. The first two weeks cover Python itself, so you do not need prior Python experience.

## Course outline

- Weeks 1-2: Python Refresher and Object-Oriented Programming
- Weeks 3-4: HTTP, REST and Building APIs
- Weeks 5-6: Relational Databases and SQL
- Week 7: ORMs and Schema Migrations
- Week 8: Authentication and Authorisation
- Weeks 9-10: Testing and Code Quality
- Week 11: Caching
- Week 12: Background Jobs and Message Queues
- Week 13: System Design Basics
- Week 14: Containers and Deployment
- Weeks 15-16: Capstone Project and Interview Preparation

## How the course runs

Each live class is three hours with a short break. Saturday classes introduce the topic and Sunday classes are mostly hands-on. Recordings are available within 24 hours.

Assignments are graded and build on each other, so the capstone is an extension of the service you have been working on through the course. You get two 1:1 mentor sessions per month.

## Payment options

At Rs 60,000 this course qualifies for no-cost EMI over 3, 6 or 9 months. Scholarships of up to 30% of the fee are available based on your entrance test score.

## Pausing the course

You can pause once for up to 8 weeks. The request must be made before week 12. See the course pause policy.
